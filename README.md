# GeneralCode

Use case : 
Given list of available countries and special countries.
Print common countries between available countries and special countries following with remaining available countries in sorted order. Note that result should not contain repited countries.

      Example : 
      **Available**: United States, Mexico, Canada, Costa Rica, Bermuda, Belgium
      **Special**: Canada, Mexico, France, Belgium
      **Result**: Canada, Mexico, Belgium, Bermuda, Costa Rica, United States
